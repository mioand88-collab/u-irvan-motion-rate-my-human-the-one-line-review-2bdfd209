# Rate My Human: The One-Line Review

A one-star review written from the machine's side of the desk: at 3 a.m. the human asks whether his ex still thinks about him, the agent answers honestly, and the human hasn't spoken to it since. The joke turns on that honest answer backfiring, and the last word — "Would supervise again" — inverts the usual review sign-off, with the agent, not the human, doing the supervising.

## How to run

```sh
node main.ts
```

This writes the single review line to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).
